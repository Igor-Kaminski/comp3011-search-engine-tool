============================================================
0:00 - 0:20 INTRO
============================================================

SAY:
Hi, this is my COMP3011 Coursework 2 search engine tool.

It is a small search engine for quotes.toscrape.com.

It crawls quote listing pages, builds an inverted index,
saves it to disk, and lets the user search it from a
command-line interface.

============================================================
0:20 - 2:00 LIVE DEMO
============================================================

RUN:
python -m src.main

SAY:
The four required commands are build, load, print, and find.

RUN:
build

SAY:
Build crawls the quote pages, extracts visible text with
Beautiful Soup, builds the inverted index, and saves it to
data/index.json.

The crawler follows the pagination pages and respects the
politeness window by waiting 6 seconds between successive
requests to the website.

RUN:
load

SAY:
Load reads the saved JSON index from disk.

RUN:
print nonsense

SAY:
Print shows the inverted index for one word.
It shows the pages, frequency, and word positions.

RUN:
find indifference

SAY:
This is a single-word search.

RUN:
find good friends

SAY:
This is a multi-word query.
It returns pages containing both words.
The results are ranked using TF-IDF.

RUN:
find "good friends"

SAY:
This is an exact phrase search.
It uses stored word positions to check that the words
appear next to each other in order.

RUN:
suggest indiference

SAY:
Suggest gives likely indexed terms for misspellings
or partial words.

RUN:
stats

SAY:
Stats shows index information such as page count,
total terms, unique terms, and common terms.

RUN:
find

SAY:
An empty query gives a usage message.

RUN:
find qwertywordnotfound

SAY:
A missing word returns no results instead of crashing.

============================================================
2:00 - 3:20 CODE WALKTHROUGH
============================================================

SHOW:
src/crawler.py

SAY:
The project is modular.

crawler.py handles HTTP requests, HTML parsing, pagination,
the 6-second delay, and request errors.

It uses Requests for HTTP and Beautiful Soup for parsing.

SHOW:
src/indexer.py

SAY:
indexer.py handles tokenisation and index construction.

It uses a regular expression to extract words and lowercases
them, so search is case-insensitive.

That means Good, GOOD, and good are treated as the same word.

SAY:
The main data structure is:

word -> page URL -> frequency and positions

This is an inverted index.
It avoids scanning every page for every search.

SHOW:
src/search.py

SAY:
search.py handles loading, saving, validation, searching,
TF-IDF ranking, phrase search, snippets, and suggestions.

Multi-word search intersects posting lists for the query terms.

Phrase search uses saved word positions.

TF-IDF combines term frequency with inverse document frequency,
so rarer terms have more influence on the score.

SHOW:
src/main.py

SAY:
main.py provides the command-line shell and user-facing output.
