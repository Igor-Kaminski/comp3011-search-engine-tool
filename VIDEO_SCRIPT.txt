0:00 - 0:20 INTRO

SAY:
Hi, this is my COMP3011 Coursework 2 search engine tool.

It is a small search engine for quotes.toscrape.com.

It crawls quote listing pages, builds an inverted index,
saves it to disk, and lets the user search it from a
command-line interface.

============================================================
0:20 - 2:00 LIVE DEMO
============================================================

RUN:
python -m src.main

SAY:
The four required commands are build, load, print, and find.

RUN:
build

SAY:
Build crawls the quote pages, extracts visible text with
Beautiful Soup, builds the inverted index, and saves it to
data/index.json.

The crawler follows the pagination pages and respects the
politeness window by waiting 6 seconds between successive
requests to the website.

RUN:
load

SAY:
Load reads the saved JSON index from disk.

RUN:
print nonsense

SAY:
Print shows the inverted index for one word.
It shows the pages, frequency, and word positions.

RUN:
find indifference

SAY:
This is a single-word search.

RUN:
find good friends

SAY:
This is a multi-word query.
It returns pages containing both words.
The results are ranked using TF-IDF.

RUN:
find "good friends"

SAY:
This is an exact phrase search.
It uses stored word positions to check that the words
appear next to each other in order.

RUN:
suggest indiference

SAY:
Suggest gives likely indexed terms for misspellings
or partial words.

RUN:
stats

SAY:
Stats shows index information such as page count,
total terms, unique terms, and common terms.

RUN:
find

SAY:
An empty query gives a usage message.

RUN:
find qwertywordnotfound

SAY:
A missing word returns no results instead of crashing.

============================================================
2:00 - 3:20 CODE WALKTHROUGH
============================================================

SHOW:
src/crawler.py
Scroll to:
- class QuoteCrawler
- crawl()
- _fetch()
- _find_next_page_url()

SAY:
The project is modular.

QuoteCrawler is the crawler class.

crawl() controls the crawl loop and follows pagination.

_fetch() sends the HTTP request and applies the 6-second
politeness delay after the first request.

_find_next_page_url() finds the next page link using several
HTML patterns.

It uses Requests for HTTP and Beautiful Soup for parsing.

SHOW:
src/indexer.py
Scroll to:
- tokenize()
- build_inverted_index()

SAY:
tokenize() extracts words with a regular expression and
lowercases them.

That makes search case-insensitive.

That means Good, GOOD, and good are treated as the same word.

build_inverted_index() creates the main inverted index.

The main data structure is:

word -> page URL -> frequency and positions

This is an inverted index.
It avoids scanning every page for every search.

SHOW:
src/search.py
Scroll to:
- class SearchEngine
- load()
- validate()
- find()
- suggest()
- _contains_phrase()
- _tf_idf_score()
- _make_snippet()

SAY:
SearchEngine contains the main search behaviour.

load() reads the saved index from disk.

validate() checks that the index structure is sensible.

find() handles normal search and multi-word queries.

Multi-word search intersects posting lists for the query terms.

_contains_phrase() checks exact phrase matches using positions.

_tf_idf_score() ranks results using term frequency and inverse
document frequency.

_make_snippet() builds short result snippets from indexed tokens.

suggest() handles prefix and spelling suggestions.

SHOW:
src/main.py
Scroll to:
- class SearchShell
- execute()
- _build()
- _load()
- _print()
- _find()
- _suggest()
- _stats()

SAY:
SearchShell provides the command-line interface.

execute() chooses which command to run.

_build(), _load(), _print(), and _find() are the four required
coursework commands.

_suggest() and _stats() are extra commands for advanced features.
